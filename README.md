# TaskButler
TaskButler is a Python-based command-line task manager with attitude. It doesn’t just track your tasks — it roasts your procrastination, prioritizes like a boss, and charts your chaos into pretty graphs. Whether you need motivation, sarcasm, or a to-do list with flair, TaskButler delivers.

✨ Features

📝 Add Tasks with deadline and auto-prioritization using smart keyword scoring.

🧠 Priority Engine that scores your task based on urgency and keywords (like "ASAP", "important", "someday"... yes, we judge).

📊 Visual Charts using Matplotlib & Seaborn to view task priority and urgency distribution.

🔥 Roast Mode that gently bullies you for slacking.

📁 Export Tasks to CSV for record-keeping or evidence of productivity.

🕵‍♀ View Upcoming Tasks due within N days.

✅ Mark and Remove Completed Tasks.

📄 Auto-Summary generation in text file format for your records.


💡 Tech Stack

NLTK for tokenization & keyword detection

Pandas for task handling

Matplotlib & Seaborn for plotting

CLI (No GUI used)
